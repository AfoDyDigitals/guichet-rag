# guichet-rag
Guichet answers questions about French administrative procedures for international students. Questions can be asked in English or French; the source documents are in French. The project compares search methods and measures which one finds the right answer most often.

## Data
- Source: Service-Public.gouv.fr / DILA, "Fiches pratiques et ressources de Service-Public.gouv.fr Particuliers"
- File: `vosdroits-latest`, downloaded 11 October 2026 from https://www.data.gouv.fr/datasets/fiches-pratiques-et-ressources-de-service-public-gouv-fr-particuliers
- Licence: Licence Ouverte v2.0
- Corpus: 417 pages, split into 7,551 sections
